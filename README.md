
# Sources of my website

For the website itself, go to:

[https://thibautjombart.netlify.app/](https://thibautjombart.netlify.app/)


# Updating the content

1. Modify files in `content/`
2. In R, run `blogdown::build_site()``
3. Commit and push files

Deployment should be triggered automatically by Netlify.
